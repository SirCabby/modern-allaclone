# Classic Items of Interest

# A hand-kept list of classic-era gear worth chasing. Offered on the item search
# page as a "list": with it picked, the search returns nothing outside it.
#
# Format -- see App\Console\Commands\IndexItemLists:
#   @title <name>     what the picker calls this list (the slug is the filename)
#   # ...             a comment; only at the start of a line, since item names
#                     of their own carry '#' ("Room Key # 6")
#   <name>            one item, matched on its exact name
#   <name> Set        every worn piece whose name starts with <name> -- unless an
#                     item is really called "<name> Set", which then wins
#   <name> = <id>     pin an exact peq.items.id, for a name two items share
#   - <name>          drop a piece the Set line above it pulled in by mistake
#
# Rebuild with `php artisan items:index-lists`, after `items:index-eras`: which
# of two same-named items is meant is settled by which one the era index knows.
#
# The comments below are the zones the list was grouped by. They are only
# comments -- nothing here is filtered by zone.
